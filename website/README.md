# OryxOS 项目主页

对应需求 5.13、台账 P-10 和验收 A-13。当前交付为仓库内静态主页，公网发布尚未完成。

## 查看

直接用浏览器打开 [index.html](index.html)，无需 Node、npm 或 Maven。保留同目录的 CSS、JavaScript，以及上级 `docs/`，文档入口即可离线访问。

也可在仓库根目录启动本地服务器：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/website/`；结束后按 Ctrl+C。浏览器禁止剪贴板访问时，复制按钮会选中命令并提示手动复制。

## 设计与维护

- 浅色背景、绿色强调色、中文优先，用户已选择该视觉方向。
- 参考 [mq9 主页](https://mq9.robustmq.com/) 的信息组织：定位、核心能力、架构、快速开始。页面排版、图形和代码为本项目编写，未复制其标识、图片或宣传数据。
- 页面使用原生 HTML/CSS/JavaScript；无远程字体、CDN 或第三方脚本。未新增 Maven 模块或 Web 服务。
- `index.html` 维护内容与命令，`styles.css` 维护响应式布局，`main.js` 仅处理复制按钮。JavaScript 不可用时仍可阅读、导航和手动复制命令。
- 更新版本号时，同步页面命令与根 POM。CLI 示例是真实可运行入口；Agent 架构图和五大能力明确标为设计目标。
- 当前没有远端仓库和许可证，不提供虚构 GitHub、下载或发布入口。
- 正式发布前需确定域名、托管和公开资料范围；部署时保留 `website/` 与 `docs/` 的相对路径，或对应调整链接。只上传 `website/` 会导致文档链接失效。
